# Тестовые процедуры агента

- **Не говори «ни разу», не прочитав журнал с начала.** UI показывает «Load earlier» и подгружает
  хвост журнала сессии; выводы вида «эта ветка не срабатывала ни разу» по хвосту — ошибка наблюдения
  (случай 04.10.2026: по хвосту показалось, что инъекция памяти не работала никогда; при разборе
  с первого события нашлись срабатывания на ходах 7, 13 и 31 — все на шаге 1).
  Правило: прежде чем утверждать отсутствие, прочитать **все** события (в т.ч. сжатые фреймы) и
  перечислить найденные срабатывания с номерами хода/шага.
- **Наблюдаемость — побочный продукт работы, а не отдельный логгер.** Состояние (время, ход, шаг,
  ветка, ключи, размер, кап) пишется из того же места, где обновляется рабочее состояние, — иначе
  оно может разойтись с реальностью. Пример: `agent-memory/injection-log.json` и строка в self-check.
- **Ход считается проверенным по телу запроса к модели, а не по возвращённому решению хука.**
  Для этого — заглушка `plugins/dsh-tool-agent-kit/tests/support/model-stub.mjs` (пишет все тела
  запросов в jsonl; режимы ok/retry-3/fail-always/quota-402/stream-break).
